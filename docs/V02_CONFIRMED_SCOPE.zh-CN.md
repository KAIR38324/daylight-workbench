# 首版范围确认与实现计划（2026-10-20 更新）

此前 0.1 基础闭环是集成验证，不是完整需求的交付。以下为本轮用户已确认的首版范围；是否完成以实际验证记录为准。

## 建模

- ANN、随机森林 RF、XGBoost 三类模型。
- ANN 使用可增删隐藏层的逐层结构图、宽度与激活函数表单，支持训练参数设置；不做任意拖线的神经网络编辑器。
- 每个目标显示 MAE、MSE、R²，保留 RMSE。指标保留原单位和目标名称，不用单个综合分数代替逐目标诊断。
- ANN 实时显示训练/验证损失、当前轮次、最佳轮次和早停状态。树模型显示真实适用的训练进度，不伪造 ANN 损失曲线。

## 超参数搜索

- 默认严谨模式：先锁定 15% 测试数据；其余约 85% 进行 5 折交叉验证。相同设计、重复输入及同组样本不得跨折。
- ANN 的早停集从每个训练折内部再划分，不使用外层验证折早停。
- 所有模型/候选共用同一外层划分，缩放器只拟合相应训练部分。
- 网格配置显示候选组合、折数和训练预算；可以取消，不默默扩大搜索。网络结构按完整结构候选组合，避免逐层参数无意产生巨大网格。
- 提供快速单次训练/验证/测试划分模式；快速模式和交叉验证模式的结果明确标识，不混为同一排行榜。
- 模型选择不使用测试集。最终模型及训练轮数规则确定后，才使用独立测试集评价。综合搜索指标是可解释、明确标注的选择依据，不能代替逐目标 MAE/MSE/R²。

## 多目标优化

- 从最终模型实际训练子集和列定义，自动建立变量名称、顺序及观测值域；旁边同时显示可编辑搜索范围。
- 默认搜索范围不超出训练数据支持范围，允许用户缩小范围、固定变量与明确变量类型；不根据列名或观察到的少量值擅自推断物理含义。
- 使用 NSGA-II，实时显示代数、评估数量、前沿变化和任务状态。
- 用户明确选择只设置变量范围与目标方向，优化完成后筛选。不新增通用硬约束编辑器或物理约束求解模块。
- 优化结果仍是代理模型预测候选，物理有效性需外部 LBT/Radiance/EnergyPlus 重新验证。

## 交互分析

- 可交互 2D/3D 帕累托散点、平行坐标刷选、联动方案表、悬停信息与稳定候选 ID。
- 优先保证交互质量，允许 Windows 分发包增大；图表 JS 等资源必须本地打包，断网可用。
- 轻量支持已有结果 CSV/XLSX 导入，手动指定目标及方向，复用可视化、筛选和导出。只有目标列时只分析目标；含设计变量时一起展示。无 Wallacei 专属文件解析或 GH 双向连接。

## LLM（本版必做）

- 默认 DeepSeek，预置官方服务地址和可编辑模型项，用户在软件中填写密钥，不在聊天中提供。
- 仅把自然语言转换为结构化筛选/排序计划，经验证和用户审阅后在本地确定性执行；不允许模型改写预测值、构造新候选或执行任意代码。
- 默认不发送训练集或候选明细。发送前展示具体提供方和请求内容；模型 API 调用有单独计费。
- 密钥仅保留于当前会话，不进入项目、仓库、日志或明文配置。联网测试必须与本地模拟接口测试区分。
- 含糊的“更好/更均衡”不能悄悄变成任意偏好，应要求明确指标或呈现待确认条件。

## 数据使用边界

用户提供的旧 CSV 明确仅用于学习格式和结构。其表头对应关系可能错误，不据此解释物理意义、不作为科研效果验收依据、不上传 GitHub。开发与自动化测试使用明确标注的合成数据。

## 工程验收

- 原有数据泄漏、非法表头、模型保存重载、取消/异步界面测试继续保留。
- 新增三类模型保存重开预测一致性、交叉验证与内部早停隔离、网格预算/取消/失败处理和各目标指标复算测试。
- 图表需要实际交互验证，不以静态截图代替刷选/联动通过。
- LLM 使用模拟响应测试结构校验、字段白名单、数据不变性、敏感信息不泄漏和发送确认；无真实密钥时不声称真实在线调用通过。
- Windows 原生构建与打包后的程序自检是交付门槛；源码测试通过或 EXE 文件生成均不等于已可交付。

## 后续确认：视觉与分析扩展

- 主界面改为白色、简洁、现代的专业工具风格。统一字体、间距和表单层级，减少粗重表格边框及大段提示。不做渐变、发光、装饰性营销卡片或“AI 风格”标识。
- 交互分析增加目标两两散点矩阵、指标分布与已选位置叠加、已选方案原始单位对比、输入—目标相关性热图。
- 热图仅描述当前候选样本的相关关系，尤其优化样本本身可能带有选择偏差，不应解释为因果。
- 表格、二维/三维散点、平行坐标和新增分析视图使用稳定候选 ID 联动；同一选择必须高亮一致，排序/筛选不可按旧行号错配。
- 没有 WebGL 的环境使用真正可交互的 SVG 二维/平行坐标回退；三维可用性必须据实际渲染能力说明，不能用警告面板或静态图宣称测试通过。
